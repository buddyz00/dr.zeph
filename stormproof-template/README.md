# Stormproof Landing Page Template

A responsive, platform-neutral recreation of the Stormproof Relationships landing-page structure. It uses plain HTML, CSS, and JavaScript and can be adapted to WordPress, Webflow, Kajabi, Squarespace, Netlify, GitHub Pages, or another platform.

## Preview locally

Download the project folder and open `index.html` in a browser. For a local server, run `npx serve .` from this folder.

## Customize

- Edit all page copy and links in `index.html`.
- Change the palette, typography, spacing, and breakpoints through the variables and rules in `styles.css`.
- Replace remote image URLs with local files in an `assets/` folder before final production.
- Connect both demo forms to your email or CRM provider. They intentionally do not transmit or store data.
- Replace the testimonial placeholders with approved, authentic testimonials.

## Files

- `index.html` — semantic page structure and content
- `styles.css` — complete desktop and mobile presentation
- `script.js` — mobile navigation, modal, current year, and demo form feedback

## Notes

The live source page currently includes placeholder testimonials and an unrelated finance-course sentence. This template replaces those with clearly editable relationship-focused copy. Original media remain hosted by the existing Kajabi CDN; download and self-host media you own before leaving Kajabi.
